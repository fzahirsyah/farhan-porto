Aplikasi kantor Notaris & PPAT · versi checkpoint 1 (Fase 0–2)

Tidak perlu instalasi. Cukup buka file HTML dengan Google Chrome atau Microsoft Edge versi terbaru.

Cara memulai

1
Ekstrak (unzip) seluruh folder notakris. Jangan memindahkan file keluar dari foldernya — folder notaris/, klien/, shared/, dan assets/ harus tetap bersebelahan.
2
Klik ganda notaris/index.html → aplikasi kantor terbuka di Chrome.
3
Pilih Database demo (data contoh lengkap), Database kosong (untuk kantor Anda sendiri), atau Buka file .sqlite.
4
Buka klien/index.html di tab lain pada jendela Chrome yang sama. Kedua tab memakai database yang sama dan saling memberi kabar secara langsung.

Coba sinkron antar-tab

  1. Di tab kantor, masuk sebagai Anindya. Di tab klien, klik Kirim sinyal uji ke kantor → lonceng notifikasi di tab kantor bertambah dan muncul pemberitahuan.
  2. Di tab kantor, buka Pengaturan → Pengguna dan tambah pengguna → daftar aktivitas di tab klien langsung berubah.

Data & cadangan

  • Database berupa SQLite yang berjalan di dalam browser dan tersimpan otomatis di penyimpanan browser (IndexedDB) setiap ada perubahan.
  • Unduh cadangan di Pengaturan → Database → Unduh database (.sqlite). File ini bisa dibuka dengan DB Browser for SQLite, dan bisa dipulihkan kembali dari menu yang sama.
  • Menghapus data situs/riwayat browser akan menghapus database. Unduh cadangan secara berkala.
  • Email tidak benar-benar dikirim; semua email aplikasi (termasuk kode masuk Portal Klien) masuk ke Outbox.

Batasan penting

Ini versi demo yang berjalan sepenuhnya di satu browser. Aplikasi kantor dan portal klien berbagi satu database di komputer yang sama, sehingga orang yang membuka alat pengembang browser dapat melihat seluruh data. Untuk dipakai klien sungguhan dari HP mereka sendiri, aplikasi perlu dipindahkan ke server dengan login yang aman.
  • Integrasi AHU, OSS, Coretax, payment gateway, e-meterai, dan daftar sanksi resmi disimulasikan.
  • Diuji di Chromium (Chrome/Edge). Browser lain belum didukung untuk komunikasi antar-tab dari file lokal.
  • Font memakai Google Fonts bila ada internet; tanpa internet tampilan memakai font sistem.
